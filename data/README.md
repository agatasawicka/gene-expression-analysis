# gene-expression-analysis

# Data
The notebook expects a CSV file named 'GDS3713-small.csv'.

The source dataset is GEO accession GDS3713, titled
"Smoking effect on B lymphocytes in females."

The file used by this notebook contains a subset of 3,000 expression
features. Its source, layout, and loading requirements are described below. 

## Data availability

The input file is included as 'data/GDS3713-small.csv'.

In Google Colab, upload this file when prompted. For local execution, leave it 
in the 'data/' directory.

## Source and citation

The original experimental data were generated by the investigators of the following study:

Pan F, Yang TL, Chen XD, Chen Y, et al.
Impact of female cigarette smoking on circulating B cells in vivo:
the suppressed ICOSLG, TCF3, and VCAM1 gene functional network may
inhibit normal cell function.
Immunogenetics. 2010;62(4):237–251.

- Publication: [PMID 20217071](https://pubmed.ncbi.nlm.nih.gov/20217071/)
- Dataset: [GEO GDS3713](https://www.ncbi.nlm.nih.gov/sites/GDSbrowser?acc=GDS3713)

This repository presents a separate educational exploratory analysis
of a feature subset. It does not reproduce all analyses or conclusions
in the original publication.

## CSV provenance

The file `GDS3713-small.csv` was provided as teaching material for Fondamenti di Informatica at the University of Pavia, Italy.

It contains 79 samples and 3,000 expression features. I did not generate
the original experimental data or select this feature subset.

The procedure used to select the 3,000-feature subset is not currently
documented in this repository.

## Expected CSV layout

The notebook reads `GDS3713-small.csv` as a comma-separated text file.

The file contains 3,000 gene-expression columns followed by a final
column named `stress`, which identifies the sample group.

### Row Structure

1. Header row: gene or feature names, followed by `stress`.
2. Feature-type metadata row: `continuous` for expression columns,
   with group-category information in the final column.
3. Class metadata row: empty expression fields and `class` in the
   final column.
4. Sample rows: numeric expression values, followed by either
   `control` or `cigarette smoke`.

The reader skips the two metadata rows before processing the samples.

### Dataset dimensions

After excluding the header and two metadata rows, the supplied CSV
contains:

- 79 samples.
- 40 samples labelled `control`.
- 39 samples labelled `cigarette smoke`.
- 3,000 expression features per sample.

### How the notebook reads the file

The `read_patients_data()` function:

- Uses a comma as the separator.
- Takes feature names from every header field except the last.
- Skips the two metadata rows.
- Reads the sample group from the last column.
- Converts all preceding fields to floating-point expression values.
- Assigns sequential identifiers such as `patient_1` and `patient_2`.

These identifiers are generated by the notebook; they are not original
study participant identifiers.

### Data-handling notes

- Use the CSV directly with the notebook. An Excel `.xlsx` workbook is
not a substitute for this input format.
- The current reader expects both metadata rows to be present. Do not
remove them unless you also update the reader.
- The group column must remain last. Do not move it to the first column
unless you also update the reader.
- Avoid opening and resaving the source CSV through spreadsheet software
without checking that numeric values and the file layout are preserved.
